# BJJ Academy Finder

Landing page responsiva para praticantes de Jiu-Jitsu, com informações sobre graduações, curiosidades da modalidade e busca de academias próximas utilizando CEP.

## Demo

[Ver Projeto Ao Vivo](https://carlospaulon.github.io/bjj-landing-page/)


## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- ViaCEP API
- Google Maps

## Funcionalidades

- Landing page totalmente responsiva
- Sistema de temas dinâmicos por faixa
- Modal para seleção de faixa
- Informações sobre graduações do Jiu-Jitsu
- Curiosidades sobre a modalidade
- Busca de academias por CEP
- Integração com a API ViaCEP
- Exibição de academias próximas no Google Maps
- Formulário de inscrição interativo

## Objetivos do Projeto

Este projeto foi desenvolvido para praticar e demonstrar conhecimentos em:

- HTML semântico
- CSS moderno e responsivo
- JavaScript ES6+
- Consumo de APIs REST
- Manipulação do DOM
- Programação assíncrona (`async/await`)
- Integração com serviços externos
- Organização de código e componentes reutilizáveis

## Como Executar

Clone o repositório:

```bash
git clone https://github.com/carlospaulon/bjj-landing-page.git
```

Abra o projeto utilizando uma destas opções:

### Live Server (Recomendado)

Abra o projeto no VS Code e execute a extensão **Live Server**.

### Servidor local

```bash
# Python
python -m http.server 8000
```

ou

```bash
# Node.js
npx serve
```
